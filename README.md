Financial Health Dashboard
A live web app that analyzes real-time financial data for MSFT, AAPL, AMZN and GOOGL.
Live App: https://financial-health-dashboard-brdvwumjqh7ffdpu5l6yry.streamlit.app

Tools
Python, Pandas, Plotly, yFinance, Streamlit, Yahoo Finance API

Features
- 10+ financial ratios calculated from live data
- KPI cards, trend charts and interactive scorecard
- Custom financial health score out of 100
